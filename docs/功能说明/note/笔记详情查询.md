# 功能说明：笔记详情查询

> **接口**：`GET /api/notes/{id}` · **模块**：`note`（主）+ `favorite`（收藏态）+ `catalog`(课程/标签) + `config`(Redis 缓存)\
> **相关设计**：《概要设计》§5.4 详情接口、§4.1 状态可见性、§6.5 收藏与占位、§6.2 预览判定、§6.7 头像链路、§3.3 计数；《技术选型》§5（V2 缓存条目）

***

## 1. 功能描述

已登录的用户打开任意一篇笔记的详情页。服务端先对 `note` 行做一次**浏览量原子自增**（仅 `ONLINE` 生效），再取回主干 + 标签——这一步走 **Redis 读缓存**（TTL 10 分钟）：未命中则查库并回填，Redis 故障则降级直查库。最后装配响应。**已下架 / 已删除的笔记同样返回 200**，元数据一条不少，只丢文件字段，并由前端提示已下架或已删除。

### 1.1 请求

```
GET /api/notes/12
Authorization: Bearer <jwt>
```

### 1.2 处理流程

```mermaid
flowchart TD
    A["浏览者打开详情页<br/>GET /api/notes/{id}"] --> B["登录态校验"]
    B -->|未登录 / token 无效| E1["40100"]
    B --> C["浏览量原子自增'"]
    C --> D{"详情缓存命中？<br/>GET note:meta:{noteId}"}
    D -->|是| H["取出 NoteMeta<br/>主干行 + 标签"]
    D -->|否，或 Redis 异常降级| F["查库<br/>selectDetail（五表 JOIN）<br/>+ selectTagRefs"]
    F -->|row 为 null| E2["40400"]
    F --> G["回填缓存<br/>TTL 10 分钟"]
    G --> H
    H --> I["装配响应<br/>status→枚举 · 非 ONLINE 时 file 置 null<br/>previewMode 现推 · 头像键→URL<br/>isFavorited 按浏览者查"]
    I --> J["200<br/>已下架 / 已删除照常返回"]
```
