# 技术选型总览

| 分层 | 选型 | 说明 |
|---|---|---|
| 运行环境 | Java 21（LTS） | Spring Boot 4 的最低基线为 Java 17 |
| 后端框架 | Spring Boot 4.0.8 | 单体起步，逐步拆服务；服务内部按 DDD 四层 |
| 远程调用 | Spring Cloud OpenFeign 5.0.0 | 由 Spring Cloud 2025.1.0 BOM 管理；消费方定义端口与适配器，不共享接口 jar |
| 注册/配置中心 | Nacos 3.1.1（client） | 阶段 1 只启用服务发现，配置中心后续再接 |
| 网关 | Spring Cloud Gateway 5.0.0<br/>`spring-cloud-starter-gateway-server-webflux` | 统一入口|
| 构建工具 | Maven | 依赖管理与打包 |
| 安全框架 | Spring Security + JWT（jjwt 0.13.0） | 无状态登录态，接口统一鉴权 |
| 持久层 | MyBatis-Plus 3.5.17 | 通用 CRUD + 分页插件，复杂 SQL 写 XML |
| 数据库 | MySQL 8.x（InnoDB / utf8mb4） | 本地 8.0 / Docker 8.4；模糊查询 + 索引分页满足 MVP 搜索 |
| 向量库 | PostgreSQL + pgvector | RAG 知识库的分块与向量检索；版本待定 |
| 消息队列 | RabbitMQ 4 | `rabbitmq:4-management` |
| 缓存 | Redis 8 | 用于笔记详情读缓存 `note:meta:{noteId}`；登录限频仍用本地内存实现 |
| 前端框架 | Vue 3.5 + Vite 8 + TypeScript | Composition API，前后端分离 |
| UI 组件库 | Element Plus 2.14 | 配合栅格/断点做移动端响应式，一套页面覆盖手机与 PC |
| 前端基础库 | Vue Router 4.6、Pinia 4、Axios 1.20 | 路由、状态管理、HTTP 客户端 |
| 文件存储 | 阿里云 OSS SDK 3.18.5 | 统一 StorageService 接口封装；后端经**内网 Endpoint** 访问 |
| 文件预览 | 浏览器原生（图片/文本）+ marked/DOMPurify/highlight.js（Markdown） | 只预览图片与 Markdown / 文本 |
| 邮件 | Spring Boot Mail + QQ 邮箱 SMTP | 用于密码找回 |
| AI 能力 | Spring AI 2.1.0 + DeepSeek（deepseek-flash） + | 上传/编辑页「自动生成摘要」：图片走多模态、md / txt 走纯文本调用，见 §2 |
| 接口文档 | Apifox | 接口设计、文档与联调；IDEA 插件从代码同步 |

## Spring Cloud 栈版本对齐

> 核对日期：2026-11-16。以下版本取自 Maven Central 元数据与本仓库父 POM。

| 组件 | 版本 | 锁定位置 / 说明 |
|---|---|---|
| Java | 21 | 父 POM `java.version` |
| Spring Boot | 4.0.8 | 父 POM `parent.version` |
| Spring Cloud | 2025.1.0 | 父 POM `spring-cloud.version`，导入 `spring-cloud-dependencies` BOM |
| Spring Cloud Alibaba | 2025.1.0.0 | 导入 `spring-cloud-alibaba-dependencies` BOM；按 Boot 4.0.x / Cloud 5.0.x 编译 |
| Spring Cloud Gateway | 5.0.0 | Cloud BOM 管理；5.0.x 补丁已到 5.0.4，升级 Cloud BOM 时一并升 |

| Spring Cloud LoadBalancer | 5.0.0 | Cloud BOM 管理；网关 `lb://` 与 Feign 服务名解析需要 |
| Nacos Client | 3.1.1 | 由 SCA BOM 传递 |
| Nacos Server | 3.1.1（建议） | 镜像 `nacos/nacos-server:v3.1.1`；v3.3.0 亦可 |
| Spring AI | 2.0.1 | 父 POM `spring-ai.version` |
| MyBatis-Plus | 3.5.17 | 父 POM `mybatis-plus-bom` |
| jjwt | 0.13.0 | 父 POM `jjwt.version` |
| 阿里云 OSS SDK | 3.18.5 | 父 POM `aliyun-oss.version` |
