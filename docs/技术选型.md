# 技术选型总览

| 分层 | 选型 | 说明 |
|---|---|---|
| 运行环境 | Java 21（LTS） | Spring Boot 4 的最低基线为 Java 17 |
| 后端框架 | Spring Boot 4.0.8 | 单体应用，controller/service/mapper 分层 |
| 构建工具 | Maven | 依赖管理与打包 |
| 安全框架 | Spring Security + JWT（jjwt） | 无状态登录态，接口统一鉴权 |
| 持久层 | MyBatis-Plus | 通用 CRUD + 分页插件，复杂 SQL 写 XML |
| 数据库 | MySQL 8.0（InnoDB / utf8mb4） | 模糊查询 + 索引分页满足 MVP 搜索 |
| 消息队列 | RabbitMQ| 由 `deploy/docker-compose.prod.yml` 起 `rabbitmq:4-management` |
| 缓存 | Redis | 用于笔记详情读缓存 `note:meta:{noteId}`；登录限频仍用本地内存实现 |
| 前端框架 | Vue 3 + Vite + TypeScript | Composition API，前后端分离 |
| UI 组件库 | Element Plus | 配合栅格/断点做移动端响应式，一套页面覆盖手机与 PC |
| 前端基础库 | Vue Router 4、Pinia、Axios | 路由、状态管理、HTTP 客户端 |
| 文件存储 | 阿里云 OSS | 阿里云 OSS SDK for Java 读写，统一 StorageService 接口封装；后端经**内网 Endpoint** 访问 |
| 文件预览 | 浏览器原生（图片/文本）+ marked/DOMPurify/highlight.js（Markdown） | 只预览图片与 Markdown / 文本 |
| 邮件 | Spring Boot Mail + QQ 邮箱 SMTP | 用于密码找回 |
| AI 能力 | Spring AI + DeepSeek| 上传/编辑页「自动生成摘要」：图片走多模态、md / txt 走纯文本调用，见 §2 |
| 接口文档 | Apifox | 接口设计、文档与联调；IDEA 插件从代码同步 |
| 部署 | Nginx + 可执行 Jar（systemd 托管） | Nginx 托管前端静态资源并反向代理后端 |
